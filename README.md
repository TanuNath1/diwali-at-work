# Diwali at Work

Free Diwali toolkit for HR and managers by Vantage Circle: send a Diwali badge card to a colleague, greeting emails, a five-day recognition plan, celebration ideas and gifting tips.

Static site, single `index.html`. No build step.

- `badges/` Diwali badge PNGs and a ZIP of all eight
- `gifts/` CC0 photos from the WordPress Photo Directory (placeholders)
- `diwali-at-work-toolkit-2026.pdf` printable toolkit, generated from `index.html?print` with Chrome's print-to-PDF

Deploy: Cloudflare Pages, framework preset "None", build command empty, output directory `/`.
